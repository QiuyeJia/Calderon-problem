# Calderon-problem

This is a repository to record a project on the Calderon's problem.
The potential goals are the following.

1. Obtain a streamlined version (with minor modifications) of the solution to the Calderon problem released by OpenAI (https://github.com/openai/math/tree/main/preprints/Smooth-Anisotropic-Uniqueness-in-the-Calderon-Problem-from-One-Boundary-Patch-September-24-2026).

2. Weaken the regularity assumption of the conductivity and the domain.

3. Try to obtain a general principle of extending and using the mixed Green function of PDEs.
